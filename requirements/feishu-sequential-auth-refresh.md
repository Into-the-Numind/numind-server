# 飞书连续授权卡片与过期刷新修复

## 来源
- 提出人：Dev 测试用户
- 提出日期：2026-07-20

## 需求描述
用户在 Agent 中创建飞书多维表格、数据表、字段和记录后，Agent 为重新读取记录申请第二项飞书权限。后台已经创建第二张授权卡片，但当前页面没有实时展示；刷新页面后卡片才出现。由于发现过晚，链接已经过期，点击“重新生成链接”又返回 `Internal server error.`。

## 业务目标
让同一个 Agent 任务发生连续多次飞书授权时始终可见、可继续、可刷新，不要求用户刷新页面，也不因正常过期状态返回 500；同时保持用户、飞书连接代次、授权会话、飞书应用、原操作和 Agent 任务的严格绑定，不重放已经执行过的 Base 写操作。

高
