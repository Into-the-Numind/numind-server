# LLM 模型切换

## 来源
- 提出人：产品负责人
- 提出日期：2026-04-10

## 需求描述
让 SOP 和智能体（Chatbot）都具备切换 LLM 模型的能力。用户在输入框附近可以选择不同的模型，包括 Claude、GPT、Gemini、豆包等，所有模型通过 DMXAPI 统一调用。每次打开时记住用户上一次的模型选择。所有用户等级均可使用模型切换功能。

## 业务目标
- 提升用户体验：让用户根据偏好和场景选择最合适的模型
- 差异化竞争：提供多模型选择是 AI 工作台的核心能力
- 为未来按模型差异定价打基础

## 优先级
高

## Triage
- 推荐轨道：Standard
- 分类理由：
  1. 数据库 schema 变更：是（需存储可用模型列表、用户模型偏好）
  2. 新增 API 端点：是（模型列表查询、用户偏好保存/读取）
  3. 新外部服务集成：否（复用现有 DMXAPI）
  4. 影响文件数：>3（后端 biz/controller/store + 前端 UI，SOP 和智能体两条路径）
  5. 高风险业务逻辑（支付/权限）：否（所有用户等级均可使用）
- 人类决定：确认 Standard

## 备注
- 模型提供商统一走 DMXAPI 聚合平台
- 需考虑不同模型的计费差异（token 单价不同）
- 需考虑模型不可用时的 fallback 策略
