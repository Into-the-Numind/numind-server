# 飞书历史授权卡片恢复

日期：2026-07-16

## 问题

一张在授权刷新修复上线前生成的飞书卡片仍显示“链接已过期”。用户点击“重新生成链接”时，开发环境返回 `Internal server error.`。

服务日志确认：该任务仍在等待连接，任务摘要指向旧会话；旧会话已是 `superseded`。这是旧实现曾产生的半完成状态，不是新流程再次写出了错误绑定。

## 目标

在不放宽用户、代际、任务、授权阶段与权限范围边界的前提下，让这种历史半完成卡片能够重新生成一个有效的授权链接，并继续原 Agent 任务。

## 验收

1. 当等待任务摘要精确指向同一任务的已作废旧会话时，刷新请求成功返回新的授权动作，而非 500。
2. 新动作仍通过现有事务性重绑和工作器放行流程生成。
3. 普通过期卡片、跨用户/代际/任务会话及仍有活动租约的替换会话继续拒绝。
4. 不保存临时链接、设备码或任何凭据。
