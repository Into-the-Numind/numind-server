# 自助配置工具（Chatbot + SOP 配置器）

## 来源
- 提出人：产品负责人
- 提出日期：2026-04-09

## 需求描述
在现有 numind 平台上新增 B 端自助配置能力，包含两类工具：

### 工具一：Chatbot 智能体配置器
B 端客户可自助配置一个 chatbot 智能体：
- 自定义系统提示词（system prompt）
- 自由选择挂载的知识库（与现有知识库体系的关系待 S1 讨论）
- 配置完成后发布，作为智能体在 C 端首页呈现
- 支持随时编辑、管理、下线

### 工具二：SOP 步骤工作流配置器
B 端客户可自助配置多步骤 SOP 工作流：
- 自定义步骤数量
- 每个步骤的提示词自定义
- 配置完成后发布，作为 SOP 在 C 端首页呈现
- 支持随时编辑、管理、下线

### 关键约束
- **B2B2C 模式**：B 端客户配置 → C 端用户使用
- **多租户隔离**：B 客户发布的智能体/SOP 仅对该 B 客户下的 C 端用户可见
- **计费归属**：C 端用户使用时，积分/tokens 消耗算在 C 端用户头上
- **管理入口**：通过管理端（numind-admin-web）操作配置
- **首页展示**：智能体区和 SOP 区分区展示（沿用现有分区）

## 业务目标
赋予 B 端客户自主搭建、快速搭建的能力，降低平台运营方的人工配置成本，实现 B 端客户自助上线工作流/智能体给其 C 端客户使用。

## 优先级
高

## Triage
- 推荐轨道：Standard
- 分类理由：
  1. 数据库 schema 变更：是（智能体配置表、SOP 模板配置表、步骤表、知识库挂载关系表等）
  2. 新增 API 端点：是（配置 CRUD、发布/下线、C 端展示等大量新 API）
  3. 新外部服务集成：否（复用现有 LLM 和知识库服务）
  4. 影响文件数：>3（预估 30+ 文件，涵盖 model/store/biz/controller/前端页面）
  5. 高风险业务逻辑（支付/权限）：是（C 端积分扣费 + 多租户可见性隔离）
- 人类决定：确认 Standard
