# 飞书授权成功后原任务恢复失败

## 来源
- 提出人：客户验收反馈
- 提出日期：2026-07-18

## 需求描述
用户完成飞书文档写权限授权后，页面显示“授权步骤已完成，正在继续原任务”，随后出现 `Internal server error`。Dev operation `23fb5145-2a01-4e22-affc-c84718a1628e` 证明授权完成，但原任务在业务写入前失败。

## 业务目标
授权成功后自动恢复同一个 Agent 工具调用；已授权权限不得被误判为临时失败，也不得重复执行写操作。

## 优先级
高

## Triage
- 推荐轨道：Standard
- 分类理由：
  1. 数据库 schema 变更：否
  2. 新增 API 端点：否
  3. 新外部服务集成：否
  4. 影响文件数：≤3 个业务/测试文件，外加 NDF 工件
  5. 高风险业务逻辑（支付/权限）：是，涉及第三方授权与写操作恢复
- 人类决定：确认 Standard，要求快速完成并部署 Dev

## 备注
固定版本 `lark-cli 1.0.68` 在全部权限已授予时输出 `missing: null`。现有解析器错误地要求 `missing` 必须是非 nil 数组。
