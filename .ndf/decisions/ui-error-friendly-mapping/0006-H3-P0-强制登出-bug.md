# H3 P0 强制登出 bug

**Date:** 2026-05-15

**Feature:** `ui-error-friendly-mapping`

**Migrated from:** `build-manifest.yaml` decisions[]

---

用户 dev 验收时报：积分不足用户在 salesrag 发消息会被立即重定向到登录页（强制登出，无提示）。Root cause: src/api/sales.ts:490 fetchSSE 的 `if (401 || 403) clearAuth + redirect` blanket 处理 — 后端 salesrag 控制器对积分不足返回 errno.ErrForbidden.SetMessage(reason) = HTTP 403，被 fetchSSE 误判为 token 失效。axios interceptor (request.ts:250) 早有正确的细粒度判断（仅当 isTokenMissing 或 isTokenError 时才登出），fetchSSE 是 copy-paste 但漏了细粒度逻辑。同模式 bug 在 SOP useSSEStream 不存在（402/403 仅 dispatch event）。Fix: fetchSSE 拆 401 (always logout) vs 403 (nuanced: parse body → 检查 token vs 业务，业务 403 抛友好 error 同时派发 insufficient-credits 事件)，逻辑与 axios interceptor 对齐。commit ed4b0c0 fix/salesrag-403-no-logout 已 merge develop 7963772 + push。
