**Date:** 2026-05-18

用户拒绝 admin 管理层（'如果是这一层的话就没必要了'）+ 明确销售智能体应该是 owner tag 模式而非 feature permission 模式（'你需要给销售智能体打上一个标签'）。架构重画：销售智能体的 owner 落点 = user.has_sales_agent BOOLEAN 字段（销售智能体不是被创建的资源，是平台内置能力，tag 挂在父账户身上语义最自然）。HasFeaturePermission 改为查 has_sales_agent 字段，移除 parent_user_id IS NULL 硬 bypass。彻底剔除 parent_feature_permission 表 + admin UI + admin API 概念。多租户原则锁定：哪个父账户创建/拥有，只有该父账户及其子用户可见，纯 SQL 过滤无人工管理层。numind-admin-web 仓库不再涉及。
