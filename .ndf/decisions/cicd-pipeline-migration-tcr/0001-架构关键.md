代码同步方式从 git clone 改为 rsync — 实测 GitHub→成都构建机 git clone 是 37 KB/s（500MB numind-server .git history 要小时级），换成 Mac→构建机 rsync 是 5.9 MB/s（70 秒搞定）。代价：构建机失去自给自足（部署必须从 Mac 触发），但与一人公司、手动触发的工作流完美契合。
