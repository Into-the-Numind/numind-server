# 机构自定义品牌名（org-branding）

## 来源
- 提出人：用户（产品负责人）
- 提出日期：2026-06-16

## 需求描述
机构 B 端用户可以在「设置」里输入自己的公司名称。设置后：
1. 用户端项目**左上角侧边栏**显示该公司名称；
2. 该机构下面**所有 C 端子用户**也都显示这个机构的公司名称；
3. 当机构没有设置名称时，左上角统一兜底显示 **"有数AI"**。

此外，登录页面把当前的图片 logo 换成 **"有数AI"** 这几个文字（用户端 + 管理端登录页都换）。

> 用户原话："机构 B 端用户可以在设置里输入自己的公司名称，这样项目的左上角以就会显示相应的公司的名称，包括这个机构用户下面的所有 C 端用户全都显示的这个机构的名称。如果没有名称的时候就显示"有数AI"。然后登录页面也要把那个 logo 换成"有数AI"这几个字。"

## 业务目标
- **白标（white-label）能力第一步**：让每个机构客户在产品里看到自己的品牌名，提升 B2B2C 交付的"自有感"，弱化"莫小派/第三方工具"痕迹。
- 统一把产品门面从历史的「莫小派」图片 logo 收敛到「有数AI」品牌文字（产品名是"有数"，见 [[project_naming_youshu_vs_moxiaopai]]）。
- 当前侧边栏品牌名是硬编码给单一客户的（`靓靓·海外IP研究所`），本需求把它**数据化**、按机构动态显示。

## 锁定的产品决策（2026-06-16 AskUserQuestion）
| 维度 | 决策 |
|---|---|
| 上线隔离 | **正常合并即上线**（不做 feature flag；靠代码模块化、干净独立满足"和别的部分区分开"，worktree 内开发完整后正常合 develop） |
| 谁来设置 | **B 端机构父账户自己在用户端「设置」里填**（管理端**不加**设置入口） |
| 显示范围 | **只做核心两处**：左上角侧边栏 + 登录页（不做浏览器 tab 标题、不做导出产物署名） |
| 登录页范围 | **用户端 + 管理端登录页都换**成"有数AI"文字 |

## AI 自主设计前提（技术决策，非产品问题）
- 公司名称是**纯文字**，不是上传图片 logo。
- 名称归属**机构父账户**（`parent_user_id = null` 的账户）；其下所有子账户**继承显示**父账户的名称。
- 登录页是登录前页面、拿不到所属机构，所以登录页**固定显示"有数AI"**（不随机构变）。
- 后端在 `/v1/users/me` 响应里直接给出**已解析好的有效品牌名**（父账户用自己的、子账户用父账户的、空则给空/兜底），前端只读一个字段，不在前端做父账户回查。

## Triage
- 推荐轨道：**Standard**
- 分类理由：
  1. 数据库 schema 变更：**是**（User 表新增 `company_name` 字段 + migration）
  2. 新增 API 端点：**是/扩展**（扩展 `PUT /v1/users/me` 接受 company_name + `/v1/users/me` 响应输出有效品牌名）
  3. 新外部服务集成：否
  4. 影响文件数：**>3**（跨 3 仓库）
  5. 高风险业务逻辑（支付/权限）：否（仅展示型字段，但触及 B2B2C 父子关系解析，需谨慎）
- 人类决定：**确认 Standard**（规则强制，不可降级）

## 涉及仓库

- `numind-admin-web`：仅登录页 logo `N` → "有数AI" 文字（一行级改动）
