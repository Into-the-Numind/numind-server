# WebSocket搜索功能测试指南

## 概述

本文档说明如何测试分词和卡册调取功能在WebSocket API中的集成。该功能已经成功集成到 `ws://localhost:9091/v1/chat/ws` 端点中。

## 功能特性

- ✅ **中文分词**：基于jieba分词库的智能分词
- ✅ **关键词匹配**：基于标题和标签的智能匹配算法
- ✅ **实时搜索**：通过WebSocket进行实时搜索请求
- ✅ **结果排序**：按匹配度降序排列搜索结果
- ✅ **完整集成**：与现有聊天系统无缝集成

## 测试准备

### 1. 环境要求

- Go 1.24.2+
- Python 3.7+ (用于WebSocket客户端测试)
- 数据库连接 (MySQL/PostgreSQL)
- 网络访问权限

### 2. 依赖安装

#### Go依赖
```bash
go get github.com/yanyiwu/gojieba
```

#### Python依赖
```bash
pip install websockets
```

### 3. 数据库准备

执行数据库迁移脚本创建必要的索引：
```bash
# 在数据库中执行
source docs/add_search_indexes.sql
```

## 测试方法

### 方法1：使用Shell脚本测试集成状态

```bash
# 运行集成检查脚本
./scripts/test_websocket_search.sh
```

该脚本会检查：
- 服务运行状态
- 关键词匹配功能
- 分词功能
- 项目编译
- WebSocket路由配置
- 搜索消息类型处理
- 数据库索引配置
- 搜索服务集成
- 数据库查询方法

### 方法2：使用Python客户端测试实际功能

```bash
# 运行WebSocket客户端测试
python3 scripts/websocket_client_test.py
```

该脚本提供三种测试模式：
1. **搜索功能测试** - 测试书籍搜索功能
2. **聊天功能测试** - 测试基本聊天功能
3. **全部测试** - 执行完整的测试套件

### 方法3：手动WebSocket测试

使用WebSocket客户端工具（如wscat、Postman等）连接：

## 故障排除

### 常见问题

#### 1. 连接被拒绝
```
❌ 连接被拒绝，请确保服务正在运行
```
**解决方案**：
```bash
# 启动服务
go run cmd/numind/main.go
```

#### 2. 搜索无结果
```
"content": "找到 0 本相关书籍"
```
**可能原因**：
- 数据库中没有书籍数据
- 索引未创建
- 分词器初始化失败

**解决方案**：
```bash
# 检查数据库连接
# 执行索引创建脚本
# 检查日志输出
```

#### 3. 响应超时
```
❌ 响应超时
```
**可能原因**：
- 数据库查询慢
- 分词器性能问题
- 网络延迟

**解决方案**：
- 检查数据库性能
- 优化查询语句
- 增加超时时间
