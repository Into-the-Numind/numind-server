# 第一张卡片跳过一级标题优化总结

## 问题描述

用户需求："卡片内容页的第一页 一级标题直接忽略，从二级标题开始渲染，修改下逻辑"

### 原始问题分析
- 第一张卡片通常包含大的一级标题，占用过多空间
- 用户希望第一张卡片直接从二级标题开始渲染，让内容更紧凑
- 需要修改分页逻辑，在第一张卡片中跳过一级标题

## 解决方案

### 1. 分页逻辑修改

#### 1.1 核心实现
```go
// 跟踪当前卡片索引，用于判断是否跳过第一张卡片的一级标题
currentCardIndex := 0

for i, line := range lines {
    // 在第一张卡片中跳过一级标题
    if strings.HasPrefix(line, "# ") && currentCardIndex == 0 {
        log.C(context.Background()).Infow("🚫 第一张卡片跳过一级标题",
            "line_index", i,
            "line_preview", truncateString(line, 50))
        continue // 跳过这一行，不添加到卡片中
    }
    
    // 其他逻辑...
}

// 更新卡片索引
if needNewCard && currentCard.Len() > 0 {
    // 保存当前卡片...
    currentCardIndex++ // 更新卡片索引
}
```

#### 1.2 关键特性
- **卡片索引跟踪**：使用 `currentCardIndex` 跟踪当前处理的卡片
- **条件跳过**：只在第一张卡片（`currentCardIndex == 0`）中跳过一级标题
- **日志记录**：详细记录跳过的标题内容，便于调试
- **索引更新**：在创建新卡片时更新索引
