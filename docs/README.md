## 核心功能概述

### 🎯 主要特性
- **智能文本处理**: 使用AI（通义千问/火山引擎）对用户输入进行智能分析和重构
- **模板系统**: 支持多种视觉模板，包含预览功能
- **异步处理**: 采用异步处理模式，提高系统响应速度
- **权限管理**: 支持多种会员类型（免费、订阅、资源包）
- **云存储**: 集成腾讯云COS，支持图片云端存储
- **图片渲染**: 使用wkhtmltoimage将HTML转换为高质量图片

### 🔄 处理流程
1. **权限验证** → 检查用户JWT Token和会员状态
2. **创建记录** → 创建BookM记录，设置初始状态
3. **异步处理** → 启动后台处理任务
4. **AI处理** → 调用AI服务分析和重构文本
5. **模板应用** → 根据选择的模板生成HTML
6. **图片渲染** → 使用wkhtmltoimage生成图片
7. **云存储** → 上传图片到腾讯云COS
8. **状态更新** → 更新处理状态和结果

### 🏗️ 技术架构
- **后端框架**: Gin (Go)
- **数据库**: MySQL + GORM
- **缓存**: Redis
- **AI服务**: 通义千问、火山引擎
- **云存储**: 腾讯云COS
- **图片渲染**: wkhtmltoimage
- **认证**: JWT

## 开发指南

### 添加新的AI服务商
1. 在 `internal/numind/biz/` 下创建新的服务商包
2. 实现 `BizInterface` 接口
3. 在 `AsyncBookProcessor` 中添加服务商选择逻辑
4. 更新配置文件

### 添加新的模板类型
1. 在 `Template` 模型中添加新字段
2. 更新模板渲染逻辑
3. 添加模板预览功能
4. 更新API接口

### 扩展存储后端
1. 在 `internal/pkg/util/` 下实现新的存储接口
2. 更新 `AsyncBookProcessor` 中的上传逻辑
3. 添加配置选项

## 监控和维护

### 关键指标
- 创建成功率
- 平均处理时间
- AI调用成功率
- 图片渲染成功率
- COS上传成功率

### 日志级别
- **INFO**: 正常流程记录
- **WARN**: 非致命错误，系统可继续运行
- **ERROR**: 严重错误，需要关注
- **DEBUG**: 调试信息

### 告警设置
- 处理失败率 > 5%
- 平均响应时间 > 30秒
- 资源使用率 > 80%
- 服务不可用

## 故障排除

### 常见问题

#### 1. AI处理失败
- 检查AI服务商API密钥
- 验证网络连接
- 查看AI服务商状态

#### 2. 图片渲染失败
- 检查wkhtmltoimage安装
- 验证渲染槽位配置
- 查看系统资源使用情况

#### 3. COS上传失败
- 检查COS配置
- 验证网络连接
- 查看COS服务状态

#### 4. 权限验证失败
- 检查JWT Token有效性
- 验证用户会员状态
- 查看数据库连接

### 调试工具
- 使用 `debug_markdown.sh` 调试markdown渲染
- 查看生成的HTML文件进行调试
- 使用日志分析工具查看处理流程
