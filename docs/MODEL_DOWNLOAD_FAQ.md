# 模型下载 FAQ - 会不会重复下载？

## ❓ 核心问题：每次部署都会重新下载模型吗？

## ✅ 答案：不会！模型只会下载一次

---

## 📦 模型存储位置

模型下载后会存储在两个地方：

### 1. Docker 镜像中（主要）
```
镜像层: /app/model_cache/
        └── sentence_transformers/
            └── BAAI__bge-small-zh/
                ├── config.json
                ├── pytorch_model.bin
                └── tokenizer.json
```

**特点**：
- ✅ 模型已经打包在镜像里
- ✅ 新容器启动时，模型已经在里面
- ✅ 不需要再次下载

### 2. 运行时检查（保险机制）
启动脚本会检查：
```bash
if 模型文件存在且完整:
    ✅ 跳过下载
else:
    ⚠️ 尝试下载（网络不好时可能失败）
```

---

## 🔄 完整的下载流程

### 场景 1：首次构建（模型下载到镜像）

```
Git Push
    ↓
CICD 构建镜像
    ↓
Dockerfile: 安装 sentence-transformers
    ↓
Dockerfile: 预下载模型到 /app/model_cache
    ↓
模型被打包进镜像
    ↓
推送镜像到 Docker Hub
    ↓
服务器拉取镜像
    ↓
启动容器
    ↓
启动脚本：检查模型 → 发现已存在 → 跳过下载
    ↓
✅ 应用启动（模型已就绪）
```

**耗时**：构建时下载一次（约 2-5 分钟）

---

### 场景 2：后续部署（模型已在镜像中）

```
Git Push（代码更新，模型未变）
    ↓
CICD 构建镜像
    ↓
Docker 缓存：模型层未变化，直接使用缓存
    ↓
推送镜像（模型层已存在，只推送代码变更）
    ↓
服务器拉取镜像
    ↓
启动容器
    ↓
启动脚本：检查模型 → 发现已存在 → 跳过下载
    ↓
✅ 应用启动（秒级）
```

**耗时**：几乎不增加（使用 Docker 层缓存）

---

### 场景 3：模型文件缺失（异常情况）

```
容器启动
    ↓
启动脚本：检查模型 → 发现缺失/不完整
    ↓
尝试运行时下载
    ↓
如果下载成功：
    保存到 /app/model_cache
    下次启动直接可用
如果下载失败：
    提示警告
    使用规则切分回退
    不影响应用启动
```

## 🎯 关键设计

### 1. 双层保护

| 层级 | 时机 | 作用 |
|------|------|------|
| **构建时下载** | Dockerfile | 预下载模型到镜像 |
| **运行时检查** | 启动脚本 | 确保模型可用 |

### 2. 智能检查

启动脚本不只是检查文件存在，还会检查文件完整性：

```python
# 检查关键文件
required_files = ['config.json', 'pytorch_model.bin', 'tokenizer.json']
for f in required_files:
    if not os.path.exists(os.path.join(model_dir, f)):
        return False  # 文件缺失，需要下载
```

### 3. 失败不阻塞

即使模型检查/下载失败，也不会阻止应用启动：

```bash
check_and_download_model || true  # 失败继续
```

## 🔧 如果要完全禁用模型下载

如果真的想完全禁用（不推荐，除非有特殊原因）：

### 方案 1：修改 Dockerfile（删除预下载）

```dockerfile
# 删除或注释掉这部分
# RUN mkdir -p /app/model_cache && \
#     python3 << 'EOF'
# ... 模型下载代码 ...
# EOF
```

### 方案 2：修改启动脚本（跳过检查）

```bash
# docker-entrypoint.sh
# 注释掉模型检查
check_and_download_model() {
    log_info "🔍 跳过语义切分模型检查"
    return 0
}
```

### 方案 3：设置环境变量（优雅降级）

```yaml
# 在 docker-compose 或 CICD 中设置
environment:
  - SKIP_MODEL_CHECK=1
```

然后在脚本中读取：
```bash
if [ "$SKIP_MODEL_CHECK" = "1" ]; then
    log_info "跳过模型检查"
    return 0
fi
```
