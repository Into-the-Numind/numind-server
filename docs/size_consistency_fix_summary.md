# 卡片尺寸一致性修复总结

## 问题描述

根据用户提供的两张图片分析，发现存在尺寸不一致的问题：

1. **左边图片（第一张）**：封面卡片，上半部分是深色背景，下半部分是浅蓝色背景，整体布局是上下分区的
2. **右边图片（第二张）**：内容卡片，整体是浅蓝色背景，没有上下分区

用户要求：**以右边这张为准，生成的卡片尺寸也必须以右边这张为准**

## 根本原因分析

### 1. 尺寸配置不一致
- **分页配置**：使用固定的1080×1440像素尺寸
- **HTML渲染器**：使用`100vw × 133.33vw`的相对尺寸
- **其他渲染器**：使用固定的1080×1440像素尺寸

### 2. 单位不统一
- **分页配置**：使用px单位
- **HTML渲染器**：使用rpx单位
- **其他渲染器**：使用px单位

### 3. 封面与内容卡片尺寸差异
- 封面卡片：上下分区布局，可能影响实际渲染尺寸
- 内容卡片：统一布局，尺寸更稳定

## 修复内容

### 1. 统一尺寸配置

#### 修复方案
- 所有渲染器使用统一的1080×1440像素尺寸
- 确保封面卡片与内容卡片尺寸完全一致
- 移除相对尺寸设置，使用固定像素尺寸

#### 修复代码
```go
// 分页配置 - 统一尺寸
Card: CardConfig{
    Width:  1080, // 标准尺寸: 1080×1440（3:4比例）
    Height: 1440,
    Padding: struct {
        Top    int `json:"top"`
        Right  int `json:"right"`
        Bottom int `json:"bottom"`
        Left   int `json:"left"`
    }{
        Top:    60, // 标准内边距: 60px 50px
        Right:  50,
        Bottom: 60,
        Left:   50,
    },
}
```

### 2. 统一单位设置

#### 修复方案
- 所有字体大小统一使用px单位
- 所有边距统一使用px单位
- 所有内边距统一使用px单位

#### 修复代码
```css

```

### 3. 确保封面与内容卡片尺寸一致

#### 修复方案
- 封面渲染器使用与内容卡片相同的尺寸配置
- 确保所有渲染器都使用统一的配置

#### 修复代码
```go

    config := pagination.GetDefaultConfig()
    // 严格保持与内容页一致的3:4比例（1080x1440）
    config.Card.Width = 1080
    config.Card.Height = 1440
    return config
}
```
