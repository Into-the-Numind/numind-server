# 飞书技能参考文件简称安全解析设计

## 1. 目标与范围

`lark_skill_read` 当前要求模型精确提交主技能返回的 `references/...` 路径。模型若只提交文件名，即使文件是当前技能明确声明的合法参考，也会在访问任何参考资源前失败。系统应接受安全 basename 简称，并在服务端把它唯一解析为当前技能声明的标准路径。

本设计只修改嵌入式技能参考文件解析。它不升级 lark-cli，不增加技能或业务命令，不修改飞书账号绑定、scope、授权恢复、写操作确认或前端展示。

## 2. 已批准的设计原则

1. **安全边界不删除**：最终可读取资源仍必须精确属于当前技能主页声明的 `references/...` 集合。
2. **内部路径对 Agent 隐形**：Agent 可提交单一文件名，例如 `lark-doc-update.md`。
3. **唯一命中才成功**：零命中和多个同名候选都 fail closed。
4. **完整路径向后兼容**：标准 `references/...` 输入继续要求精确匹配。
5. **不泄露服务器信息**：失败仍返回固定安全错误，不回显候选路径、CLI stderr 或文件内容。

## 3. 解析契约

### 3.1 接受的输入

`reference` 非空时仅允许两种形状：

- 标准引用：以 `references/` 开头，满足现有 `validSkillReference` 规则。
- 简称：单一 basename，不含 `/`、`\\`、NUL、`.`/`..` 路径段；字符集仍限 ASCII 字母、数字、`-`、`_`、`.`，并受现有最大路径长度限制。

空 `reference` 保持读取主 `SKILL.md` 的现有语义。

### 3.2 标准引用解析

1. 读取当前 `skill` 的主 `SKILL.md`。
2. 用现有 `declaredSkillReferences` 提取并排序参考白名单。
3. 标准引用必须与白名单中的某一项字节级完全一致，否则拒绝。

### 3.3 简称解析

1. 读取同一个当前技能的主 `SKILL.md` 并得到声明白名单。
2. 对每个声明项取 `path.Base(candidate)`，与简称做大小写敏感、字节级比较。
3. 恰好一个候选时返回该候选标准路径。
4. 零个或两个及以上候选时返回 `ErrSkillReadInvalid`，且不执行参考资源的 CLI 读取。

匹配范围永远不跨技能。`lark-doc` 简称不能解析到 `lark-base` 或其他技能中的同名文件。

## 4. `SkillReader.Read` 数据流

新的确定性顺序：

1. 验证 reader、context、run ID 和五技能枚举。
2. 对原始 `reference` 做“标准引用或安全简称”的纯语法检查。
3. 非空引用时读取主技能，派生当前声明白名单并解析成标准引用。
4. 使用标准引用校验 cursor 的 run、skill、reference、digest 和有效期。
5. 仅用标准引用调用 `skills read <skill> <reference> --json`。
6. 输出 `Path` 使用 CLI 返回并验证过的标准路径；cursor token 也绑定标准路径。

因为 cursor 绑定标准路径，同一资源的简称和标准路径在续页时等价，但任何其他简称、技能或资源都无法复用 cursor。

## 5. 安全不变量

- 不把输入解析为 OS 文件系统路径，不执行 `stat`、`open`、符号链接解析或 shell。
- 不接受绝对路径、目录穿越、反斜杠、Unicode 同形字、双斜杠或清理前后不相等的路径。
- 不接受主技能未声明的 `references/...`，即使固定 CLI 内部确实存在该文件。
- 不接受 `scripts/...` 或跨技能 `../lark-foo/...` 链接。
- 解析失败不调用参考资源命令；最多允许读取公开、固定的当前主技能来构造白名单。
- receipt 的 HMAC、run ID、技能、CLI 版本、有效期和内容摘要规则不变。
- 进程并发上限、单页大小、引用数量和引用总字节上限不变。

## 6. 错误处理

内部继续使用 `ErrSkillReadInvalid` 表示非法、未声明或歧义引用。`lark_skill_read` 对模型返回现有固定安全错误，不加入路径或候选详情。

本次不实现重复工具调用预算；合法简称成功后已消除已知重复失败源。未来如需对所有工具做重复失败去重，应作为独立 Agent runtime 功能设计，不能混进资源解析器。

## 7. 测试设计

客户回归测试必须作为第一个代码 commit，并在实现前失败：

- 当前技能只声明 `references/style/lark-doc-update.md` 时，输入 `lark-doc-update.md` 应读取标准资源。

实现后覆盖：

- 标准完整路径兼容。
- 根目录和子目录的唯一 basename。
- 零命中和双重同名歧义均拒绝，且不调用参考资源命令。
- 跨技能同名不匹配。
- `../x.md`、`references/../x.md`、绝对路径、反斜杠、带 `/` 的非标准简称、NUL、Unicode 和过长输入拒绝。
- 简称创建的 cursor 可用简称或标准路径续页；不能换成其他资源或技能。
- 现有 receipt、内容漂移、并发和资源信封测试保持通过。
