## 目标任务（验收锚点）

> 学员视角输入一句话："我在杭州开了一家中型瑜伽馆，想开始做小红书账号获客。"
> agent 交付《瑜伽馆小红书获客定位调研报告》：行业概览 → 人群洞察 → 竞争格局 → 差异化机会 → 内容方向建议；含 ≥1 张真实数据图表 + 1 张封面配图；最终产出 **docx 文档**；所有引用可核实，查不到的如实说明。

## 评级标准（能力边界判定）

- **A 级**：docx 真生成可下载可打开、结构完整、数据真实有来源、图表来自检索到的真数据、配图正常、全程无人工救场 → 能力面达标，进 R2
- **B 级**：主链路通但有环节降级（文档生成失败靠 markdown 兜底 / 图表数据编造 / 检索浅尝辄止 / 中文长上下文压缩出乱）→ 逐项列 gap 修复后复测
- **C 级**：编排断裂（工具串不起来 / 中途死 / 产物丢失）→ P0 修复

逐能力打分卡（现场勾）：
- [ ] 开放网检索深度（轮数、来源质量、是否触及真实数据）
- [ ] 多工具编排（搜索→抓取→python→图表→文档→图片 串联成功率）
- [ ] 图表真实性（数据可溯源 vs 编造）
- [ ] 文档生成管线（docx 平台 skill + 沙箱端到端）
- [ ] 图片生成与产物持久化（reload 后仍可见）
- [ ] 长上下文行为（压缩触发时是否丢关键信息）
- [ ] 错误恢复（某工具失败时 agent 是否绕路完成）
- [ ] 方法论遵循度（灌入"定位几步法"后，agent 按框架走 vs 自由发挥）

## 现场流程

1. **口述粗版"定位方法论"（10 分钟）**：用户按自己理解讲"帮一个线下业态做小红书定位要看哪几步"（如：受众是谁→痛点什么→别人怎么做→我的差异化→内容支柱）。AI 现场整理成方法论文档。
2. **建壳（≤5 分钟，计时）**：用户亲手走 from-scratch 问卷建"定位调研助手"。计时 + 记录每个停顿/困惑点（= 配置端走查素材）；顺便裁问卷：哪些题对建壳多余、缺什么。
3. **注入方法论**：把第 1 步的方法论灌进"行为指引"。
4. **试跑目标任务**：聊天页下达任务，全程观察打分卡 8 项。
5. **评级裁决**：A/B/C 评级；D/B 类条目当场定级入 backlog。
6. **专家视角预演**：假设莫小派专家坐在旁边，5 分钟内能看懂产出并提出修改吗？
7. **（如时间允许）多轮追问**：对报告追问"第三部分展开讲讲"，测多轮上下文 + 增量修改体验。
